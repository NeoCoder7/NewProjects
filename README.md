# To-Do List Application ✅

A simple yet functional Python-based To-Do List application for managing daily tasks. Perfect for learning basic Python programming concepts including file handling, data structures, and command-line interfaces.

## ✨ Features

- **Add Tasks**: Easily add new tasks to your list
- **View Tasks**: Display all tasks in an organized format
- **Strike-Off Tasks**: Mark tasks as completed with strike-through formatting
- **Delete Tasks**: Remove tasks from your list
- **Persistent Storage**: Tasks are saved and loaded automatically
- **Simple CLI**: Easy-to-use command-line interface

## 🛠️ Technologies

- **Python 3.x**: Core programming language
- **File I/O**: For data persistence
- **Built-in Libraries**: No external dependencies required

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system
- No additional packages required

### Installation

```bash
# Clone the repository
git clone https://github.com/NeoCoder7/NewProjects.git

# Navigate to project directory
cd NewProjects

# Run the application
python ToDoList.py
```

## 💻 Usage

### Running the Application

```bash
python ToDoList.py
```

### Commands

1. **Add a new task**
   - Select "Add" option
   - Enter your task description

2. **View all tasks**
   - Select "View" option
   - See all your tasks listed

3. **Strike-off a task**
   - Select "Strike-Off" option
   - Choose the task number to mark as complete

4. **Exit the application**
   - Select "Exit" option
